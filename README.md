# Examining the Effects of Ultra-Processed Foods on Mortality and Fertility in Males in the United Kingdom

## Overview

This project investigates the relationship between ultra-processed food (UPF)
consumption, male reproductive indicators and mortality/life-expectancy trends
in the United Kingdom.

## Methods

The analysis uses UK secondary datasets covering:

- Nutrient intake
- Household food purchases
- Fertility and paternal characteristics

The analysis includes:

- Data cleaning
- Data transformation
- NOVA food classification
- UPF exposure calculation
- Exploratory data analysis
- Ordinary Least Squares regression
- Newey-West corrected regression
- Lagged regression

## Files

- `EDA project.R` — R analysis code
- `Project work edited.pdf` — Full project report
- `data/` — Source datasets
- `output/` — Generated datasets and results
- `figures/` — Visualisations

## Key Finding

The analysis found a negative association between UPF exposure and
standardised mean age of father, although the findings should be interpreted
as demographic associations rather than evidence of direct biological
causation.
